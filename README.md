# kecan0406@bemani

Terminal palettes for BEMANI characters, a [ttheme](https://github.com/kecan0406/ttheme) market.

```sh
ttheme market add kecan0406/ttheme-bemani
ttheme browse
```

Each game is a catalog. Every palette's colors are measured from the character's official artwork or game art, and no pictures are included.
